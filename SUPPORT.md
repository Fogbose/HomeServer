# Support

Use [issues](https://github.com/Fogbose/HomeServer/issues) for bugs and feature
proposals with sanitized versions, commands and expected/actual behavior.
Read [operations](docs/operations.md) first. Support is voluntary and best effort.

Nextcloud application questions belong in its upstream documentation/community;
this project is not affiliated with or supported by Nextcloud, Docker or Tailscale.
For vulnerabilities use [SECURITY.md](SECURITY.md), not a public issue.
